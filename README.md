# Engram — Releases

macOS (Apple Silicon) release binaries for **Engram**, a local-first, agent-native knowledge OS. The source repository is private; this repo hosts the downloadable builds only.

Latest: see [Releases](https://github.com/AJARA-llc/engram-releases/releases). Landing page: https://engram — download the `.dmg`, open it, drag Engram to Applications.
